# 免疫塔防 · immuno-td

病毒 vs 免疫细胞的**微信小游戏塔防**原型，目标 **IAA 广告变现**。

> 当前阶段：**玩法框架已封版，单关可玩原型跑通**。多章进度、合成系统、记忆 buff、大 BOSS 章、开局准备期等均为"已定方案、未实现代码"。

---

## 一、怎么跑

### 1. 可玩原型（首选，看手感）
直接用浏览器打开 `td-core/L1_play.html` 即可（单文件 Canvas，零依赖）。
- 点「开始防御」→ 在中间绿格摆免疫细胞拦病毒 → 撑过 8 轮小怪 + 第 4 轮后 1 个 BOSS。
- 漏怪 → 体温上升 → 42° 发烧失败。

### 2. 战斗模拟器（验证难度/数值，headless）
需要 Node：
```bash
cd td-core
node main.js            # 模式A(完美greedy) + 模式B(随机商店多seed) 通关率
node verify_v04.js      # 三档摆放水平 × L1-L3 胜率
node verify_range.js    # 巨噬 range 2.0 vs 2.5 胜率对比
node sweep_range.js     # 射程倍数 × 攻击倍数 扫描
node sweep_redweight.js # 红细胞商店权重扫描
node coverage.js        # 摆位区 vs 路径 射程覆盖测算
```

## 三、核心玩法（已定框架）

- **固定路径 TD**（保卫向日葵式）：外环病毒通道 + 内格摆位区，路径每关不同、写死在 config。
- **三层资源**：格子卡（多形状开暗格）+ 细胞卡（免费摆塔）+ 能量（仅刷新）。
- **章/轮/BOSS**：10 普通章 + 2 大 BOSS 独立关 = 12 章；每章 8 轮小怪，第 4 轮后出 1 章节 BOSS；大 BOSS 章满格开局/每秒产能/无小怪。
- **成长系统（双线）**：
  - 合成主线：同型同级 2 合 1（变强 + 外观进化），场上塔 + 商店卡都能合，拖动 + 一键，全部细胞可合，**产物不压缩格子**。
  - 记忆 buff 辅线：记忆细胞观察者，按轮结算每章 3-4 次，三类混合 buff（+10~20%）。
- **替换/交换**：商店细胞卡拖到占用格 → 原塔退回商店对应槽。
- **IAA 核心钩子**：看广告定向刷（每章限 1 次，首槽强制所选卡），缓解"留卡 vs 刷新丢失"难点。

> 完整设计、待决策项、变更日志见乐享活文档：
